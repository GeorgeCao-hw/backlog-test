## 2. 页面状态详细说明

### 2.1 Step 1 — 选择验证方式

| 元素 | 说明 |
|------|------|
| 标题 | "为保障账号安全，删除前需验证身份" |
| 联系方式展示 | 邮箱和手机号**均脱敏**显示；未绑定的渠道置灰不可选 |
| 默认选中 | 优先选中邮箱；仅绑定手机时默认选手机 |
| "发送验证码"按钮 | 点击后按钮立即进入**60秒冷却**状态，显示"重新发送(60s)"倒计时 |
| "取消"按钮 | 关闭弹窗，不执行任何操作 |

**发送失败提示（Toast）：**
- 网络错误：`"发送失败，请检查网络后重试"`
- 频率限制：`"操作过于频繁，请 60 秒后再试"`

---

### 2.2 Step 2 — 输入验证码

| 元素 | 说明 |
|------|------|
| 提示文字 | 显示已发送至的脱敏联系方式 |
| 验证码输入框 | 6个独立格子，每格仅接受1位数字，自动跳格 |
| "重新发送"链接 | 发送后 60 秒冷却，倒计时结束前显示为灰色不可点击 |
| "确认删除"按钮 | 6位全部输入后激活；点击后显示 Loading 状态 |
| "取消"按钮 | 关闭弹窗，清空已输入验证码 |

**验证码错误状态：**

```
输入框变红，下方显示错误提示：

  [ 1 ][ 2 ][ 3 ][ 4 ][ 5 ][ 6 ]  ← 红色边框
  ✕ 验证码错误，还剩 2 次机会

第3次错误后：
  ✕ 验证码错误次数过多，操作已终止。请重新发送验证码。
  → 弹窗返回 Step 1（清空验证码，重置发送冷却）
```

**验证码过期状态：**
```
  ✕ 验证码已过期，请重新获取。
  → 弹窗返回 Step 1
```

## 3. 交互边界与异常处理

| 场景 | 处理方式 |
|------|---------|
| 用户未绑定邮箱也未绑定手机 | 不展示验证码弹窗，提示"请先绑定邮箱或手机号后再执行删除操作" |
| 发送过程中网络中断 | "确认删除"按钮 Loading 超时（10s）后提示"网络超时，请重试"，不关闭弹窗 |
| 用户多 Tab 同时操作 | 后发起的 OTP 覆盖先发起的，旧 OTP 自动失效 |
| 移动端适配 | 弹窗在手机端以底部抽屉（Bottom Sheet）形式展示 |
