## 3. 生产环境验证

> **参考方向**：变更后如何快速确认"系统是好的"且功能符合预期。

**验证方式：**

1. **数据入库验证**
   - 执行 Clone 采集任务后，查询数据库 `fact_{community}_clone` 表，确认数据成功写入
   - 验证数据字段完整性：uuid、namespace、repo_path、created_at、count、uniques

2. **日志检查**
   - 观察采集日志，确认 WAF 日志被正确解析
   - 检查 IP 地理位置信息是否正确（country、city、is_domestic）

3. **回归验证**
   - 执行现有采集任务，确认现有功能不受影响

## 4. 回滚方案

> **原则**：回滚必须是受控且经过验证的，**禁止现场临时拼凑命令**。

> 出现以下任意一种情况，必须立即中断变更并启动回滚：
> 1. **指标异常**：错误率超过 5% 或 P99 延迟增加超过 50% 且持续 2 分钟。
> 2. **核心阻塞**：主要业务链路中断，且无法在 10 分钟内定位根因。
> 3. **不可抗力**：变更期间发生严重的云服务中断或网络分区。

> 参考：
> * **代码/版本回滚**：使用 `git revert` 撤销变更，或基于特定版本 Tag 重新部署。
> * **配置回滚**：如涉及配置变更，恢复配置文件到变更前状态。
> * **数据回滚**：数据采集类变更无需数据回滚。

**回滚执行路径：**

| 步骤 | 回滚动作 | 执行命令/方式 | 预期结果 |
|--------|----------|--------------|----------------------------|
| **R1** | 停止调度任务 | 暂停华为云 DataArts 中 Clone 采集或 WAF 日志解析任务节点 | 停止继续写入新数据 |
| **R2** | 代码版本回退 | Revert PR 或 `git revert` 对应 commit，重新合入 | 代码恢复旧逻辑 |
| **R3** | 重新发布 | 重新执行 CI/CD 流水线 | 系统恢复正常 |
