### 3.1 功能测试专项

> 参考测试设计方向
> * 扫描编排验证：验证扫描流程的正确触发、任务协调、错误处理和重试机制
> * 日志下载验证：验证能否正确连接OBS、遍历目录、过滤最近三天的日志
> * 敏感信息检测：验证gitleaks扫描的准确性，覆盖密钥、Token、凭证等
> * 结果解析验证：验证能否正确提取namespace和pod信息，生成结构化报告
> * 报告生成验证：验证报告JSON格式、完整性、字段准确性

**功能测试用例：**

**1. 扫描编排服务框架验证**

* **对应task**: TASK1 - 扫描编排服务框架
* **测试场景**:
  - 定时任务按配置时间触发
  - CronJob创建Pod并执行扫描
  - 扫描完成后Pod清理
  - 异常情况下的重试机制
* **预期结果**:
  - 定时任务准时触发
  - Pod成功创建和执行
  - 任务状态正确转移
  - 错误时自动重试

**2. 凭证管理安全流程验证**

* **对应task**: TASK2 - 凭证管理模块
* **测试场景**:
  - Pod启动时从Secret读取凭证配置文件
  - 凭证成功加载到内存
  - 配置文件立即删除（覆写后删除）
  - 内存中的凭证可正常使用
* **预期结果**:
  - 凭证文件成功读取
  - 文件被安全删除（覆写后无法恢复）
  - 后续OBS操作使用内存中的凭证

**3. 日志扫描器功能验证**

* **对应task**: TASK3 - 日志扫描器
* **测试场景**:
  - 扫描挂载目录中的日志文件
  - 过滤出最近三天的日志
  - 支持多个云账号的日志目录
  - 处理日志格式多样性
* **预期结果**:
  - 正确识别日志文件
  - 时间范围过滤准确
  - 多云账号日志分别扫描
  - 大文件正常处理

**4. gitleaks敏感信息扫描验证**

* **对应task**: TASK4 - gitleaks集成
* **测试场景**:
  - 包含AWS密钥的日志扫描
  - 包含API Token的日志扫描
  - 包含数据库凭证的日志扫描
  - 正常日志扫描（无敏感信息）
  - 混合场景：部分敏感信息
* **预期结果**:
  - 密钥、Token、凭证被准确识别
  - 扫描结果JSON.GZ格式正确
  - 无误报或漏报
  - 性能满足要求

**5. 结果解析器功能验证**

* **对应task**: TASK5 - 结果解析器
* **测试场景**:
  - 从扫描结果中提取namespace信息
  - 从扫描结果中提取pod信息
  - 添加时间戳等元数据
  - 处理缺失或异常数据
* **预期结果**:
  - namespace和pod信息准确提取
  - 结构化报告格式正确
  - 缺失数据有默认值或标记
  - 元数据完整

**6. 报告生成和加密验证**

* **对应task**: TASK6 - 报告加密和上传
* **测试场景**:
  - 生成JSON格式的完整报告
  - 使用AES-256加密报告
  - 上传加密报告到OBS结果桶
  - 验证上传成功
* **预期结果**:
  - 报告JSON格式符合规范
  - 加密报告大小合理
  - 上传到OBS成功
  - 报告文件权限正确

### 3.4 安全与隐私测试专项

> 参考测试设计方向
> * 凭证管理：验证凭证不硬编码、启动后立即删除、内存中安全管理
> * 数据加密：验证报告AES-256加密、传输TLS加密、数据完整性HMAC验证
> * 访问控制：验证OBS结果桶权限、Pod ServiceAccount权限、RBAC配置
> * 日志脱敏：验证审计日志不包含敏感信息
> * 容器安全：验证非Root运行、只读文件系统、资源限制
> * 依赖漏洞：验证第三方依赖无已知漏洞

**安全测试用例：**

**1. 凭证管理安全性验证**

* **对应task**: SEC-TASK1 - 凭证管理模块
* **测试场景**:
  - 检查代码中是否硬编码凭证
  - 检查日志中是否打印凭证信息
  - 验证凭证从Kubernetes Secret读取
  - 验证凭证启动后立即删除（覆写后删除）
  - 验证内存中凭证不会写入磁盘
* **预期结果**:
  - 代码中无硬编码凭证
  - 日志中无凭证信息
  - 配置文件被安全删除
  - 内存中凭证受保护

**2. 报告加密和完整性验证**

* **对应task**: SEC-TASK2 - 报告加密和HMAC签名
* **测试场景**:
  - 验证报告使用AES-256加密
  - 验证报告使用HMAC-SHA256签名
  - 尝试篡改加密报告
  - 篡改后验证签名失败
  - 使用正确密钥成功解密
* **预期结果**:
  - 报告使用AES-256加密存储
  - 报告包含HMAC签名
  - 篡改报告后签名验证失败
  - 原始报告可成功解密

**3. OBS结果桶访问控制验证**

* **对应task**: SEC-TASK3 - OBS结果桶权限配置
* **测试场景**:
  - 验证未授权用户无法访问结果桶
  - 验证授权用户可读取报告
  - 验证报告文件权限设置
  - 验证Object Lock保护设置
* **预期结果**:
  - 未授权用户访问被拒绝
  - 授权用户可成功读取报告
  - 报告文件权限为600或640
  - Object Lock设置有效

**4. 审计日志脱敏验证**

* **对应task**: SEC-TASK4 - 审计日志脱敏
* **测试场景**:
  - 检查审计日志中是否包含完整的敏感信息
  - 验证日志中仅包含操作类型和时间戳
  - 验证日志中包含云账号ID但不包含凭证
  - 验证日志中不包含加密密钥
  - 检查日志保留期设置（90天）
* **预期结果**:
  - 审计日志不包含完整的密钥、Token等敏感信息
  - 日志中包含操作类型、时间戳、云账号ID
  - 日志中不包含OBS凭证和加密密钥
  - 日志保留期设置正确

**5. 容器安全策略验证**

* **对应task**: SEC-TASK5 - 容器安全策略
* **测试场景**:
  - 验证容器以非Root用户运行（runAsUser > 1000）
  - 验证容器根文件系统为只读
  - 验证容器资源限制设置（CPU/Memory）
  - 验证容器无capabilities权限
  - 验证securityContext配置完整
* **预期结果**:
  - 容器运行用户UID > 1000
  - 容器根文件系统为只读
  - CPU和内存限制已设置
  - 容器权限最小化

**6. 传输层安全验证**

* **对应task**: SEC-TASK1/2 - 安全配置
* **测试场景**:
  - 验证与OBS的通信使用TLS 1.2+
  - 验证日志下载使用HTTPS
  - 验证报告上传使用HTTPS
* **预期结果**:
  - 所有网络通信使用TLS加密
  - 无明文凭证在网络上传输

**7. 依赖漏洞扫描**

* **对应task**: SEC-TASK6 - 安全测试和渗透测试
* **测试场景**:
  - 使用SBOM工具扫描Go依赖包
  - 检查是否存在已知CVE漏洞
  - 检查gitleaks工具版本和漏洞
* **预期结果**:
  - 无高危CVE漏洞
  - 中危漏洞有修复计划
  - 关键依赖定期更新
