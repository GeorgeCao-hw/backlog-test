### 3.1 功能测试专项

> 参考测试设计方向
> * 扫描编排验证：验证扫描流程的正确触发、任务协调、错误处理
> * 日志下载验证：验证能否正确连接OBS、遍历目录、过滤最近N天的日志
> * 敏感信息检测：验证gitleaks扫描的准确性，覆盖密钥、Token、凭证等
> * 结果解析验证：验证能否正确提取namespace和pod信息，生成结构化报告
> * 报告生成验证：验证报告JSON格式、完整性、字段准确性
> * 单元测试 statement 覆盖率须 ≥ 80%

**功能测试用例：**

**1. 扫描编排服务框架验证**

* **对应task**: TASK1 - 扫描编排服务框架
* **测试场景**:
  - 扫描任务按配置时间触发
  - CronJob创建Pod并执行扫描
  - 扫描完成后Pod清理
  - 异常情况下的错误处理
* **预期结果**:
  - 扫描任务准时触发
  - 任务状态正确转移
  - 错误时正确记录日志

**2. 凭证管理安全流程验证**

* **对应task**: TASK2 - 凭证管理模块
* **测试场景**:
  - Pod启动时从配置文件读取凭证
  - 凭证成功加载到内存
  - 配置文件立即覆写删除（secureDeleteFile）
  - 内存中的凭证可正常使用
* **预期结果**:
  - 凭证文件成功读取
  - 文件被安全覆写删除（无法恢复）
  - 后续OBS操作使用内存中的凭证

**3. 日志扫描器功能验证**

* **对应task**: TASK3 - 日志扫描器
* **测试场景**:
  - 扫描挂载目录中的日志文件
  - 过滤出最近N天的日志（默认3天）
  - 支持多个云账号的日志目录
  - 处理日志格式多样性
* **预期结果**:
  - 正确识别日志文件
  - 时间范围过滤准确
  - 多云账号日志分别扫描

**4. gitleaks敏感信息扫描验证**

* **对应task**: TASK4 - gitleaks集成
* **测试场景**:
  - 包含AWS密钥的日志扫描
  - 包含API Token的日志扫描
  - 包含数据库凭证的日志扫描
  - 正常日志扫描（无敏感信息）
* **预期结果**:
  - 密钥、Token、凭证被准确识别
  - 扫描结果JSON/JSON.GZ格式正确
  - 无误报或漏报

**5. 结果解析器功能验证**

* **对应task**: TASK5 - 结果解析器
* **测试场景**:
  - 从扫描结果中提取namespace信息
  - 从扫描结果中提取pod信息
  - 添加时间戳等元数据
  - 处理缺失或异常数据
* **预期结果**:
  - namespace和pod信息准确提取
  - 结构化报告格式正确
  - 缺失数据有默认值或标记
  - 元数据完整

**6. 报告生成和上传验证**

* **对应task**: TASK6 - 报告上传
* **测试场景**:
  - 生成JSON格式的完整报告
  - 上传加密报告到OBS结果桶
  - 验证上传成功
  - 验证7天过期策略
* **预期结果**:
  - 报告JSON格式符合规范
  - 上传到OBS成功
  - 报告文件权限正确

### 3.4 安全与隐私测试专项

> 参考测试设计方向
> * 凭证管理：验证凭证不硬编码、启动后覆写删除、内存中安全管理
> * 数据加密：验证传输TLS加密、OBS私有桶访问控制
> * 访问控制：验证OBS结果桶权限、Pod ServiceAccount权限
> * 日志脱敏：验证审计日志不包含敏感信息
> * 容器安全：验证非Root运行、只读文件系统、资源限制
> * 依赖漏洞：验证第三方依赖无已知漏洞

**安全测试用例：**

**1. 凭证管理安全性验证**

* **对应task**: SEC-TASK1 - 凭证管理模块
* **测试场景**:
  - 检查代码中是否硬编码凭证
  - 检查日志中是否打印凭证信息
  - 验证配置文件启动后覆写删除
  - 验证内存中凭证不会写入磁盘
* **预期结果**:
  - 代码中无硬编码凭证
  - 日志中无凭证信息
  - 配置文件被安全覆写删除
  - 内存中凭证受保护

**2. OBS私有桶访问控制验证**

* **对应task**: SEC-TASK2 - OBS结果桶权限配置
* **测试场景**:
  - 验证未授权用户无法访问结果桶
  - 验证授权用户可读取报告
  - 验证报告文件权限设置
  - 验证7天过期策略设置
* **预期结果**:
  - 未授权用户访问被拒绝
  - 授权用户可成功读取报告
  - 报告文件权限为600或640
  - 7天过期策略有效

**3. 审计日志脱敏验证**

* **对应task**: SEC-TASK3 - 审计日志脱敏
* **测试场景**:
  - 检查审计日志中是否包含完整的敏感信息
  - 验证日志中仅包含操作类型和时间戳
  - 验证日志中包含云账号ID但不包含凭证
* **预期结果**:
  - 审计日志不包含完整的密钥、Token等敏感信息
  - 日志中包含操作类型、时间戳、云账号ID
  - 日志中不包含OBS凭证

**4. 容器安全策略验证**

* **对应task**: SEC-TASK4 - 容器安全策略
* **测试场景**:
  - 验证容器以非Root用户运行（runAsUser > 1000）
  - 验证容器根文件系统为只读
  - 验证容器资源限制设置（CPU/Memory）
* **预期结果**:
  - 容器运行用户UID > 1000
  - 容器根文件系统为只读
  - CPU和内存限制已设置

**5. 依赖漏洞扫描**

* **对应task**: SEC-TASK5 - 安全测试验证
* **测试场景**:
  - 使用Go依赖扫描工具检查漏洞
  - 检查是否存在已知CVE漏洞
  - 检查gitleaks工具版本和漏洞
* **预期结果**:
  - 无高危CVE漏洞
  - 关键依赖定期更新
