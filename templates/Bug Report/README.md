# Bug Report 模板

## 用途
缺陷报告模板，用于 Phase 1.2 缺陷驱动流程。

## 适用场景
- 在**项目代码仓库**提交缺陷 Issue（非 backlog 仓库）
- Service Owner triage 后决定是否进入修复

## 模板字段
| 字段 | 说明 |
|------|------|
| 缺陷标题 | 一句话概述缺陷 |
| 缺陷描述 | 问题现象、复现步骤、影响范围 |
| 预期行为 | 期望的正确行为 |
| 实际行为 | 当前发生的错误行为 |
| 版本/环境 | 发现缺陷的版本号或环境信息 |
