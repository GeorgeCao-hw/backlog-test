# Requirement Analysis 模板

## 用途

需求分析说明书模板，适用于 Phase 1.1 需求驱动流程。

## 适用阶段

Phase 1.1.3 — AI 写需求文档

## 产出文件

- `01-requirements.md` — 需求分析说明书
- `01-requirements-qa.md` — 需求 QA 报告（由 requirements-qa agent 产出）

## 模板要点

- 需求场景说明（2-3 句话）
- 验收标准（3-5 条可量化标准）
- 需求设计与分解（Task 2-4 个）
- 需求相关性分析（need_design / need_security / need_itest / need_ux / need_light）
- 价值识别与业务评估（Accept / Reject / Pending）
