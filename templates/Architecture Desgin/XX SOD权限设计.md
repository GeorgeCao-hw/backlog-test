# XX服务权限职责SOD设计说明

### 一、 实体定义与描述

在抽象模型中，SOD 的本质是限制特定**主体**通过**角色**在特定**客体**上执行相互冲突的**操作**。

| 实体名称               | 抽象描述                               | 实际主客体、角色、操作清单 |
|--------------------|------------------------------------|---------------|
| **主体 (Subject)**   | 权限的请求源，是访问行为的唯一标识实体。               |               |
| **角色 (Role)**      | 职能抽象层，作为主体与权限集合的中间媒介，定义了互斥边界。      |               |
| **操作 (Operation)** | 对客体施加的动作集合，分为“单向变更”、“状态转移”与“观测记录”。 |               |
| **客体 (Object)**    | 受控资源或逻辑数据项，是权限作用的终点。               |               |
